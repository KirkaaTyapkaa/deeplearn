# Прогноз для досліду (до запуску `--bug`)

1. Втрата не зміниться, бо помилка тільки в backward, а прямий прохід той самий.
2. Усі ненульові градієнти стануть у N = 105 разів більшими. dZ2 буде P - Y замість (P - Y)/N, а всі чотири градієнти рахуються з dZ2 лінійно, тому множник 105 перейде в кожен. Нульові елементи (якщо якийсь нейрон ReLU мертвий на всіх прикладах) так і залишаться нулями.
3. Звірка з PyTorch: втрата пройде, всі чотири градієнти не пройдуть. Чисельна перевірка не пройде для кожного параметра, в якого градієнт не нульовий (різниця буде 104·|g|, а це набагато більше за 1e-7). Якщо в якогось з вибраних параметрів градієнт нульовий, чисельна перевірка для нього помилку не покаже.
